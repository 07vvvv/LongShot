# LongShot

Windows 滚动长截图工具。按热键框选一块区域，用滚轮把内容滚过去，单击左键结束，得到一张完整长图。

单个 47MB 的 exe，自包含 .NET 运行时，**目标机器不需要装任何东西**。

## 用法

```
按热键  →  拖拽框选区域  →  滚轮上下滚动  →  单击鼠标左键结束
```

结束时长图会：

- 保存到磁盘（见下方「输出位置」）
- 复制进剪贴板
- 自动用系统看图器打开

首次运行会自动启用 `Ctrl+Alt+L` 作为热键，随时可以在设置界面里改。

## 特性

- **自定义全局热键**：任意 `Ctrl / Alt / Shift / Win` 组合。设置时会**试注册**检测冲突（Windows 上唯一可靠的判定方式），被占用就明确告诉你"无法设置"，含 `Win` 的组合还会要求试按确认——因为存在"注册成功却收不到"的情况。
- **双向滚动**：向下、向上都能截；往回滚到已经截过的范围不会重复追加内容。
- **DPI 感知**（PerMonitorV2）：框选范围和实际截到的范围严格一致，125% / 150% 缩放下不会错位。
- **抓取时不干扰操作**：选区确定后遮罩彻底透明且鼠标穿透，你像平时一样点击和滚动真正的应用；左键由低级鼠标钩子单独拦下用来结束。
- **异常兜底**：任何未处理异常都不会再弹出"未经处理的异常"崩溃框，而是记录到日志并给一句人话提示。

## 输出位置

长图按优先级挑选**确实可写**的目录：

1. `图片\LongShot\`
2. `LongShot.exe` 同级的 `captures\`
3. 系统临时目录

文件名形如 `longshot_20261015_231045_123.png`（精确到毫秒，连拍不会互相覆盖）。

想看当前机器上哪个目录可用：

```powershell
LongShot.exe --pathtest
```

## 快捷键配置位置

- `%APPDATA%\LongShot\hotkey.json`
- 写不进去时回退到 exe 旁边，**两处都失败会在界面上明确告知**（不会再出现"设置好了、重启就没了"却毫无提示的情况）

## 自检

程序内置了一整套可复跑的自检，都不需要人盯着：

| 命令 | 检查内容 |
|---|---|
| `--stitchtest` | 配准算法（双向偏移、步长突变、无滚动、累积模型、性能） |
| `--aligntest` | 框选坐标与抓帧坐标是否一致（放一个纯色标记窗口实地抓） |
| `--overlaytest` | 选区窗口的鼠标命中、穿透、抓帧是否被自己污染、钩子行为 |
| `--grabtest` | 屏幕抓取在本机是否真能拿到画面 |
| `--uitest` | 设置界面构造、热键管理器、清除快捷键 |
| `--pathtest` | 长图输出目录的可写性 |
| `--startuptest` | 启动耗时 |
| `--probe` | 探测一批常见组合键在本机是否被占用 |
| `--makeicon` | 重新生成 `app.ico` |
| `--uishot` | 抓设置界面和浮层的截图 |

自检输出会镜像到 `diag.log`（GUI 子系统下 stdout 不建立）。

## 启动日志

`%TEMP%\LongShot-startup.log`，每次启动追加十来行。遇到"打不开 / 卡住"时，这个文件里有完整现场：进程启动耗时、单实例判定、配置加载、热键注册结果、窗口是否显示。

## 从源码构建

需要 .NET 8 或更高版本的 SDK（Windows）。

```powershell
dotnet build -c Release
dotnet run -c Release                        # 直接运行

# 打包成单文件自包含 exe
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true `
  -p:EnableCompressionInSingleFile=true `
  -p:DebugType=none `
  -o publish
```

## 已知边界

- **粘性头部 / 固定侧栏**会在长图里重复出现——需要额外的固定区检测，暂未实现。
- **动画或视频区域**会导致配准不可信，这些帧会被跳过，长图里可能缺一小段（浮层会显示"跳过 N 帧"，并提示滚慢一点）。
- 长图总像素上限 3000 万（约 120MB 内存），到顶时浮层会提示结束后再截下一段。
- exe 未做代码签名，首次运行可能被 SmartScreen 或安全软件拦一下。
